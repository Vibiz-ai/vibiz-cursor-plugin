# Vibiz for Cursor

Vibiz is your AI marketing team. This plugin connects Cursor to the Vibiz remote MCP server (`https://mcp.vibiz.ai/mcp`).

## What you can do
- Onboard a brand from its website or Instagram URL (brand kit: logo, colors, fonts, tone, audience)
- Plan and create on-brand ad creatives: images, carousels, videos, UGC-style creator videos, product shots (credit cost shown first)
- Growth report across Meta, Google, TikTok, LinkedIn, Pinterest and X
- Read ad accounts, campaigns and ads (spend, ROAS, CTR, conversions)
- Pause/delete ads and publish or schedule social posts — always behind an approval step

## Setup
1. Install the plugin from the Cursor Marketplace.
2. On first use, Cursor opens the Vibiz sign-in (OAuth). Log in with your Vibiz account and allow access.
3. Try: "List my Vibiz brands" or "How did my marketing do last week?"

Requires a Vibiz account: https://www.vibiz.ai
